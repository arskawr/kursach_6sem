Краткое описание

Light's End – кооперативная многопользовательская 2D-игра в жанре survival horror с видом сверху. Группа выживших исследует заброшенный подземный комплекс, собирает мистические артефакты и сражается с боссом, чтобы найти выход. Главная особенность – фонарик с ограниченным зарядом, который не только освещает путь, но и отпугивает монстров, заставляя игроков тактически расходовать ресурс. Игра разработана на движке Unity с использованием библиотеки Mirror для сетевого взаимодействия и поддерживает до 8 игроков в одной сессии. Серверная авторитарная архитектура исключает читерство и гарантирует одинаковый игровой опыт для всех участников.

Системные требования

Операционная система: Windows 10 или Windows 11 (64-разрядная версия)
Процессор: двухъядерный с тактовой частотой не менее 2.0 ГГц
Оперативная память: 4 ГБ
Видеокарта: совместимая с DirectX 11, объём видеопамяти не менее 512 МБ (подойдёт интегрированная графика уровня Intel HD 4000 или аналог)
Свободное место на жёстком диске: около 300 МБ
Дополнительно: для работы функции сохранения статистики требуется установленный XAMPP (Apache + MySQL) – см. соответствующий раздел ниже.

Инструкция по запуску
 
Распакуйте архив с игрой в любую удобную папку.
Запустите файл Light's End.exe.
В открывшемся меню нажмите кнопку «Start Host», чтобы создать сервер и начать игру за первого игрока.

Если требуется добавить второго игрока на том же компьютере:

Не закрывая первый экземпляр, запустите Light's End.exe ещё раз.
В новом окне нажмите «Start Client» – клиент автоматически подключится к серверу на этом же компьютере (localhost).
Для игры по локальной сети на разных ПК:
На компьютере, который будет выполнять роль сервера, нажмите «Start Host».
